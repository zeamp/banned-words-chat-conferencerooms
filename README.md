> A clean, flat list of inappropriate words, slang, and variations sorted alphabetically. Designed for quick ingestion into databases, regex filters, or chat moderation tools for conference rooms and public event streams.

---

The dataset is provided as a simple flat text file where **each bad word is on its own new line**, formatted in lowercase and sorted alphabetically.
